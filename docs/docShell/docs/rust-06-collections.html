Coleções, closures e iterators

Se você usou Streams (Java 8+) ou .map/.filter (JS), iterators de Rust serão naturais — com a diferença de que são lazy e zero-cost: o compilador os otimiza até o nível de um loop manual.

let tema = config.get("tema");      // Option<&String>

A API entry do HashMap

Padrão que aparece o tempo todo (contadores, agrupamentos):

Java 
contagem.merge(palavra, 1, Integer::sum);
// ou:
contagem.computeIfAbsent(
    chave, k -> new ArrayList<>()
).add(valor);
Rust 
*contagem.entry(palavra).or_insert(0) += 1;
// ou:
contagem.entry(chave)
    .or_insert_with(Vec::new)
    .push(valor);

Closures

Como arrow functions do JS e lambdas de Java — com um detalhe de ownership:

let dobro = |x: i32| x * 2;
let soma = |a, b| a + b;            // tipos inferidos
let msg = String::from("olá");

// captura por referência:
let greet = || println!("{msg}");

// captura movendo (necessário p/ threads):
let greet2 = move || println!("{msg}");

Três traits por trás (não precisa decorar agora): Fn (só lê o ambiente), FnMut (muta o ambiente), FnOnce (consome valores capturados — só chamável uma vez).

Iterator: map / filter / collect

O mesmo pipeline nas três linguagens:

JavaScript 
const nomes = users
  .filter(u => u.ativo)
  .map(u => u.nome.toUpperCase());
// executa na hora (eager)
Rust 
let nomes: Vec<String> = users
  .iter()
  .filter(|u| u.ativo)
  .map(|u| u.nome.to_uppercase())
  .collect();
// lazy até o .collect()
Java 
List<String> nomes = users.stream()
  .filter(u -> u.isAtivo())
  .map(u -> u.getNome().toUpperCase())
  .toList();
Rust 
let nomes: Vec<String> = users.iter()
  .filter(|u| u.ativo)
  .map(|u| u.nome.to_uppercase())
  .collect();

Pontos importantes:

  • .iter() empresta (&T), .iter_mut() empresta mutável, .into_iter() consome (move) — o ownership se aplica à pipeline.
  • Como Streams de Java, nada acontece sem um consumidor (collect, for, sum, fold, any, count…).
  • O tipo do collect é definido pela variável/assinatura — por isso a anotação : Vec<String>.

collect com Result — pipeline que pode falhar

Padrão elegante que você usará no shell (parsear N valores, abortando no primeiro erro):

let nums: Result<Vec<i32>, _> =
    ["1", "2", "x"].iter().map(|s| s.parse::<i32>()).collect();

match nums {
    Ok(v) => println!("{v:?}"),
    Err(e) => println!("falhou em: {e}"),
}

O collect encaixa uma pipeline de Result num único Result<Vec> — o primeiro Err vence.

Índices: esqueça o for i

for (i, app) in apps.iter().enumerate() {
    println!("{i}: {app}");
}
