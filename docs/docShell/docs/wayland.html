Mecânicas essenciais

  • Frame callbacks — o compositor avisa quando é hora de desenhar o próximo frame
  • Configure events — o compositor propõe tamanho/estado; você responde
  • Commit — você "publica" o estado da surface (double buffering do protocolo)

Exemplo 1 — primeiro cliente Wayland

Um cliente mínimo e compilável que conecta ao seu compositor, descobre os globals e cria uma surface. É a anatomia de todo cliente Wayland em Rust — a barra do shell nasce daqui.

// Cargo.toml:
// [dependencies]
// wayland-client = "0.31"

use wayland_client::{
    protocol::{wl_compositor, wl_registry, wl_surface},
    Connection, Dispatch, QueueHandle,
};

// 1. O estado da aplicação — os eventos vão mutá-lo
struct App {
    running: bool,
    surface: Option<wl_surface::WlSurface>,
}

// 2. Handler do registry: onde os globals são descobertos
impl Dispatch<wl_registry::WlRegistry, ()> for App {
    fn event(
        state: &mut Self,
        registry: &wl_registry::WlRegistry,
        event: wl_registry::Event,
        _dados: &(),
        _conn: &Connection,
        qh: &QueueHandle<Self>,
    ) {
        // o compositor anuncia cada global com nome e versão:
        if let wl_registry::Event::Global { name, interface, version } = event {
            println!("global: {interface} v{version}");

            if interface == "wl_compositor" {
                // 3. bind: cria o proxy da interface que interessa
                let compositor = registry.bind::<wl_compositor::WlCompositor, _, _>(
                    name,
                    version.min(4),
                    qh,
                    (),
                );
                // 4. cria a surface — a área onde desenharemos depois
                state.surface = Some(compositor.create_surface(qh));
            }
        }
    }
}

// 5. TODO proxy precisa de um impl Dispatch — mesmo sem eventos
impl Dispatch<wl_compositor::WlCompositor, ()> for App {
    fn event(_s: &mut Self, _c: &wl_compositor::WlCompositor, _e: wl_compositor::Event,
             _d: &(), _conn: &Connection, _qh: &QueueHandle<Self>) {}
}

impl Dispatch<wl_surface::WlSurface, ()> for App {
    fn event(_s: &mut Self, _surf: &wl_surface::WlSurface, _e: wl_surface::Event,
             _d: &(), _conn: &Connection, _qh: &QueueHandle<Self>) {}
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    // conecta via WAYLAND_DISPLAY (default: wayland-0) = wl_display
    let conn = Connection::connect_to_env()?;

    // fila de eventos: tudo que o compositor mandar cai aqui
    let mut event_queue = conn.new_event_queue();
    let qh = event_queue.handle();

    // primeiro request: pegar o registry para descobrir globals
    let _registry = conn.display().get_registry(&qh, ());

    let mut app = App { running: true, surface: None };
    event_queue.roundtrip(&mut app)?;      // processa o estado inicial

    println!("surface criada? {}", app.surface.is_some());

    // o loop de eventos — dorme quando não há nada (sem busy loop!)
    while app.running {
        event_queue.blocking_dispatch(&mut app)?;
    }
    Ok(())
}

O que está acontecendo, mapeado para os conceitos do protocolo:

  • Connection::connect_to_env() → wl_display: o socket do compositor (rode num Sway/Hyprland/Niri real).
  • get_registry() → wl_registry: o compositor anuncia cada global como um evento — por isso a descoberta é um impl Dispatch, não uma função de retorno.
  • registry.bind() → cria o proxy da interface; a partir daí você chama requests (como create_surface) nele.
  • Dispatch é o receptor de events: um método por tipo de objeto, match no enum de eventos.
  • roundtrip() sincroniza (garante que tudo pendente foi processado); blocking_dispatch() é o loop que dorme até chegar evento — exatamente o modelo "event → reage → espera" da página de performance.
  • Repare nos conceitos da Parte 1: Result/?, Option no estado, generics com trait bounds (Dispatch<I, ()> for App).

Antes de escrever código, rode wayland-info (pacote wayland-utils) no seu sessão: ele lista os globals que o SEU compositor oferece. Se um protocolo não aparece lá, seu shell não pode usá-lo.
