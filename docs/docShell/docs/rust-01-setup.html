Configuração do ambiente e Cargo

Se você já usou npm ou Maven, o Cargo vai parecer familiar: ele é npm + jest + eslint + prettier + javadoc em um binário só.

Instalando via rustup

rustup é o gerenciador de toolchains do Rust (pense nvm/pyenv, mas oficial). Instale com:

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Isso instala no seu ~/.cargo (sem sudo):

  • rustc — o compilador
  • cargo — build tool + gerenciador de pacotes
  • rustfmt — formatador (≈ prettier)
  • clippy — linter (≈ eslint/checkstyle)

Não instale Rust via apt install rustc ou similar — versões de distro costumam estar defasadas e o ecossistema se move rápido. Use sempre rustup e mantenha tudo atualizado com rustup update.

Verificando a instalação

rustc --version
cargo --version
rustup doc

rustup doc abre a documentação completa offline — incluindo "The Book", que será sua principal referência.

Estrutura de um projeto

hello_cargo/
├── Cargo.toml        # ≈ package.json / pom.xml
├── Cargo.lock        # ≈ package-lock.json — commit sempre em binários
├── src/
│   └── main.rs       # ponto de entrada
└── target/           # ≈ build output (gitignored)

O Cargo.toml mínimo:

[package]
name = "hello_cargo"
version = "0.1.0"
edition = "2021"

[dependencies]

Diferença importante do npm: as dependências são baixadas para um cache global (~/.cargo/registry), não para uma pasta node_modules por projeto. O registry é o crates.io — equivalente ao npmjs.com.

Hello World

fn main() {
    println!("Hello, world!");
}

Dois detalhes que já contam muito:

  • fn declara funções; main é o ponto de entrada (como public static void main).
  • println! tem uma exclamação porque é uma macro, não uma função. Macros compilam para código especializado em tempo de compilação. Você verá ! bastante: vec![], format!, assert_eq!…
fn main() {
    let nome = "mundo";
    println!("Hello, {nome}!");        // interpolação direta
    println!("Hello, {}!", nome);      // com argumento posicional
}

Editor

Recomendação: VS Code + extensão rust-analyzer. O rust-analyzer dá autocomplete, type hints inline, e — crucial — explica erros do compilador com sugestões de correção. As mensagens de erro do Rust são as melhores da indústria: leia-as com atenção, elas quase sempre dizem exatamente o que fazer.

Habilite o clippy no editor instalando a extensão e rodando cargo clippy de vez em quando. Ele pega idiomas errados que o compilador deixa passar.

Exercícios

  1. Crie um projeto hello_cargo com cargo new, rode com cargo run.
  2. Modifique o programa para imprimir seu nome usando interpolação.
  3. Compile em modo release (cargo build --release) e execute o binário direto de target/release/.
  4. Instale o Rustlings (cargo install rustlings) — ele será seu companheiro nos próximos capítulos.
